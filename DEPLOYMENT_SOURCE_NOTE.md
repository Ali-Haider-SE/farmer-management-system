# Deployment/source note

The public AppDeploy URL is a deployed React/AppDeploy adaptation of the Farmer Management System. The local source archive here is the original VS Code-runnable Flutter + Node.js + PostgreSQL project supplied for local development.

Live AppDeploy URL:
https://farmer-management-system-6xc9sx.v2.appdeploy.ai/

The AppDeploy-hosted backend uses AppDeploy services and is not the same process/database as the local PostgreSQL backend in this archive. Therefore, this archive is the appropriate package for running the actual project independently in VS Code with PostgreSQL.
